# Internationalisation

## Two separate languages
1. **Interface language** — buttons, labels, errors. Per user (`profiles.ui_locale`), shown in the URL (`/ar/…`).
2. **Course content language** — chosen by the teacher on T1 when generating (`courses.content_locale`). A French course can be studied in an English interface.

## Locales
| Locale | Direction | v1 |
|---|---|---|
| `en` English | LTR | Default, complete |
| `ar` Arabic | **RTL** | Complete at launch |
| `fr` French | LTR | Ready (machine-translated, then reviewed) |
| `es` Spanish | LTR | Ready (machine-translated, then reviewed) |

## Tooling
- `next-intl` with locale-prefixed routes; middleware detects locale from profile → cookie → `Accept-Language` → `en`.
- Messages in `src/messages/{locale}.json`, namespaced by area: `common`, `auth`, `teacher.classes`, `teacher.builder`, `student.player`, `errors`…
- ICU message format for plurals and variables: `"{done}/{total} complete"`, `"{count, plural, one {# student} other {# students}}"`.
- Type-safe keys (missing key = TypeScript error); CI fails if a locale is missing keys.

## RTL
- `<html lang dir>` set on the server from the locale.
- **Logical CSS only**: `ms-`/`me-`/`ps-`/`pe-`, `start`/`end`, `text-start` — never `left`/`right`, `ml-`/`mr-`.
- Directional icons (arrows, chevrons, "Next →") flip in RTL; progress bars fill from the start edge.
- Join codes, numbers and code stay LTR inside RTL text (`dir="ltr"` / `<bdi>`).
- Arabic font fallback added to the system stack (system Arabic font) so line height stays consistent.

## Formatting
- Dates, numbers and percentages through `Intl` with the interface locale ("Nov 4" / "٤ نوفمبر").
- Due dates are stored as dates (no time zone); "Overdue" compares against the user's local date.

## AI output
- Generation prompts receive the content language explicitly; the Ask Claude tutor answers in the course's language unless the student writes in another.
- Diagram text uses the course language; RTL diagram text gets `direction="rtl"` in the sanitiser.

## Copy style
Follow the design system's content rules: sentence case, name the action on every button, say what to do next in errors.
