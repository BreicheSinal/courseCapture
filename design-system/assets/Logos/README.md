The CourseCapture mark and wordmark, as SVG. Everything is plain geometry or outlined type, so it scales without loss.

- `mark.svg`, `mark-dark.svg`: the rounded-square mark on Light and on Dark.
- `mark-ink.svg`, `mark-white.svg`: the symbol alone in one color.
- `lockup.svg`, `lockup-dark.svg`: mark and wordmark side by side. The default logo.
- `wordmark.svg`, `wordmark-dark.svg`: the name alone.

Pick the Light file on `bg` or `surface` in Light and the Dark file in Dark. Leave clear space of half the mark's height. See the Logo section of the README.
