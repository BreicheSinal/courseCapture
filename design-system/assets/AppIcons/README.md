Icons for the installed app and the browser tab.

- `favicon.svg`: the tab icon, a rounded-square mark.
- `app-icon.svg`: full-bleed square with no rounded corners, for iOS and app stores, which round it themselves.
- `app-icon-maskable.svg`, `icon-maskable-512.png`: the symbol inside the Android safe zone for the maskable purpose.
- `apple-touch-icon-180.png`: the 180px icon for the home screen on iOS.
- `icon-192.png`, `icon-512.png`: the PWA manifest icons, with transparent corners.
